# destiny-dice
**🎲 브라우저에서 즐기는 운명의 주사위, 싱글플레이와 멀티플레이로 즐기세요!**

---

## 소개
**Destiny Dice**는 웹 브라우저에서 바로 즐길 수 있는 미니 보드게임입니다.  
주사위를 굴려 말을 이동시키고, **싱글플레이에서는 봇**과, **멀티플레이에서는 친구와 함께** 플레이할 수 있습니다.  
UI는 끄투와 마크에서 살짝 영감을 받아 직관적으로 디자인되었습니다.

---

## 기능
- **싱글플레이**: 봇과 턴 기반 게임
- **멀티플레이**: 랜덤 ID 생성, 방 생성/입장, 준비 완료 기능
- 주사위 굴리기 애니메이션
- Canvas 기반 보드판과 말 이동
- 턴 표시와 플레이어 리스트 GUI
