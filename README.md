# 🎲 Destiny Dice

**브라우저에서 즐기는 운명의 주사위**  
싱글플레이와 멀티플레이로 가볍게 즐기는 웹 기반 미니 보드게임

---

## 📌 소개

**Destiny Dice**는 별도의 설치 없이 웹 브라우저에서 바로 플레이할 수 있는  
턴 기반 미니 보드게임입니다.

주사위를 굴려 말을 이동하며 목표 지점에 먼저 도달하는 것이 목적이며,  
**싱글플레이에서는 봇과**, **멀티플레이에서는 친구와 함께** 플레이할 수 있습니다.

UI는 **끄투**와 **마인크래프트**에서 영감을 받아  
누구나 직관적으로 이해할 수 있도록 구성되었습니다.

---

## ✨ 주요 기능

### 🎮 게임 모드
- **싱글플레이**
  - 봇과 1:1 턴 기반 플레이
- **멀티플레이**
  - 랜덤 ID 기반 방 생성
  - 방 입장 / 나가기
  - 플레이어 준비 완료 시스템

### 🎲 게임 시스템
- 주사위 굴리기 애니메이션
- Canvas 기반 보드판 렌더링
- 말 이동 애니메이션
- 턴 표시 및 현재 플레이어 강조

### 🧩 UI / UX
- 실시간 플레이어 리스트
- 현재 턴 시각적 표시
- 직관적인 버튼 및 인터페이스
